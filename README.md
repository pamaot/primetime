Hey folks,  

This is a small tool that helps managing simulcast streaming sites.

You can add the URL inside your `watchlist.txt` along with some additional information.  
The tool will show all your watchlist items that match your `config.txt`.

---

## Version

- **v1.0** – Complete decentralized management via `config.txt` / `watchlist.txt`  
- **v2.0** – Simple UI for centralized management inside the tool -> not pushed yet because still in develope

---

## Installation

1. Clone the repository:
```bash
git clone https://github.com/pamaot/primetime.git
```

2. Switch to the desired release:
```bash
cd primetime
git checkout release/[Version]
```
Or shorter:
```bash
git clone -b release/[Version] https://github.com/pamaot/primetime.git
```

## Updates

To check for updates, open the console in the tool directory and run:
```bash
git pull
```
